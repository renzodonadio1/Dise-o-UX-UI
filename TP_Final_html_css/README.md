## ⚽ Sobre el Proyecto
**Encuadre & Gol** es un sitio web *one-page* diseñado para un taller especializado en el enmarcado artesanal de camisetas de fútbol de colección, reliquias deportivas y fotografías históricas. 

El proyecto combina un enfoque de diseño minimalista y moderno con una arquitectura de información semántica, responsive y accesible, cumpliendo con los estándares de diseño UX-UI y desarrollo web.

---

## Concepto Visual & UX
- **Personalidad de Marca:** Artesanal, Histórico, Pasión, Galería.
- **Paleta de Colores:** Neutros oscuros (`#0f172a`, `#020617`), blancos puros para legibilidad y acentos visuales con fotografías reales de colección e identidad futbolera.
- **Tipografía:** Sans-serif limpia con variantes de peso para marcar jerarquía de encabezados.

---

## Stack Tecnológico
- **HTML5 Semántico**: Uso de etiquetas estructurales (`header`, `nav`, `main`, `section`, `article`, `footer`) y jerarquía estricta de encabezados.
- **Tailwind CSS**: Maquetación responsive basada en Flexbox y CSS Grid.
- **Vanilla JavaScript (ES6+)**: 
  - Control interactivo del menú hamburguesa en dispositivos móviles.
  - Validación del formulario de contacto.

---

## Estructura de Secciones
1. **Header / Navegación:** Logo, navegación ancla y menú móvil interactivo.
2. **Hero:** Propuesta de valor, imagen destacada y CTAs de conversión.
3. **Nosotros / Sobre el Taller:** Explicación técnica del enmarcado (cajas de sombra, protección UV).
4. **Skills / Técnicas & Materiales:** Tarjetas sobre conservación textil, vidrios técnicos y marquería con fondo de césped sintético.
5. **Catálogo / Casos de Estudio:** Grilla interactiva con fotografía real de trabajo terminado.
6. **Experiencia / Trayectoria:** Línea de tiempo (*timeline*) con los hitos del taller artesanal.
7. **Contacto:** Formulario estilizado con fondo icónico del Superclásico (River/Boca).
8. **Footer:** Copyright, enlaces sociales y navegación secundaria.
